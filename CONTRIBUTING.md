# Contributing

## Workflow
- Use pull requests (PRs) for all non-trivial changes.
- Keep PRs small and focused when possible.
- Link issues or add context in the PR description.

## Code quality
- Follow repository formatting/linting conventions.
- Add tests when feasible; explain if not.

## Sensitive content
- Do not commit secrets, credentials, tokens, or private data.
- Do not upload large datasets; link to data sources instead.
